四档立体奖章，采用深绿珐琅、象牙色 T 和逐级增加的金属／镶嵌结构。阈值、日期和用户数据由界面排版，不烘焙在图片中。

## 使用规格

- 四张 WebP 均为 768 × 768，保留透明通道，总计约 482 KiB。推荐大图 260–300 CSS 像素、收藏列表 120–156 CSS 像素。
- 白底成就页展示完整轮廓；首次解锁使用独立的深绿色展示层，以金色柔光烘托奖章。
- 解锁动效约 880 ms：奖章小角度旋入、回弹至稳定位置、一次切面闪光和少量光点。可立即关闭；减少动态效果时直接显示静态结果。
- 页面保留累计、单日和连续上传三个分类。数字、条件达成日和进度使用真实数据，不加入称号或劝分享口号。
- 分享图包含奖章、门槛、必要的用量摘要与固定小程序码。固定码只代表进入小程序，不能宣称动态指向分享者页面。
- 图片未包含用户昵称、账号标识、生产用量或凭证。

## 实现边界

当前提交是**设计资源和交互规格**，尚未接入正式小程序页面或服务端发放逻辑，不代表已经上线。

接入时需满足：

1. 服务端用账号和规则版本保证一次发放，独立保存首次展示状态；重新安装或换手机不能重复自动弹出。
2. 同次满足多枚条件时，首次打开只展示最高一枚，其余合并为计数；不连续播放多个弹层。
3. 真实历史用量可以评估 Token 门槛。连续上传须增加上传日记录，不能把历史使用日期当成上传日期。
4. 使用当前有效设备、含缓存总用量和北京时间口径；数据修正、重置、禁用、注销时重新评估或清除关联状态。
5. 公开分享页先展示内容；成就、隐私、接入、提醒弹层应协调，避免连续打断。

生成方式与提示词规格见 [prompts.md](prompts.md)，文件校验值见 [manifest.json](manifest.json)。
