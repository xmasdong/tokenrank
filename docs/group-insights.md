# 群用量与分享

群榜周期标签下直接展示本群 Token 总量、USD API 等值估算、活跃人数及用量最多的工具／模型。「分析与分享」进入同群完整数据：输入／输出／缓存构成、工具与模型占比、使用人数、主用人数和按日趋势。支持今日、近 7 天、近 30 天，全部按北京时间，含缓存，与群榜取同一公开统计范围。

- `GET /api/groups/:id/insights?period=day|week|month`：需要有效登录且属于该群；只读当前统计设备，排除禁用、全站隐藏和本群隐藏成员。无头像或昵称的成员仍参与汇总。汇总全体成员，不从榜单前 50 名拼接。
- 工具／模型由同一次数据库读取计算；主用人数只在该成员最大具名分类超过未分类部分时计入。工具与模型是独立分类，不能据此推断工具内部模型对应关系。明细重叠时用分类明细合计计算比例并标注。
- 未同步日期为 `null`，真实零保留为 0。今日及近 7 天显示最近 7 天趋势，近 30 天显示最近 30 天趋势；标题区总量仍严格使用所选周期。
- 金额为上游上传的 API 等值估算，非实际账单；缺少金额不补零。部分计价时标注覆盖缺失，`missing_user_days` 为缺金额的成员日记录数，`missing_days` 为涉及的去重日期数。

## 分享

`POST /api/groups/:id/insights/share` 使用服务端重新计算的周期数据，只接受 `period` 与有效 `snapshot`。与所看数据版本不一致返回 409，要求刷新确认；不接受客户端提交的用量或金额。

分享使用现有 `usage_shares` 表，无新迁移，默认 90 天有效。相同快照复用记录，沿用每天生成上限。公共入口 `/pages/group-report/group-report?id=…` 免登录先看来源群快照，可切换工具／模型、查看趋势、再次转发或分享 PNG；底部「去看我的用量」才进入个人页面。该入口不会识别或创建接收方群榜。原有「转发完整榜单／邀请群友」仍按接收方真实微信群识别，一群一榜。

公开记录只有群级汇总，不含群身份、成员 ID、设备 ID、个人日明细或登录凭证。内部保存参与者可见性校验信息，公开读取时去掉；创建者退群、参与者退群／隐藏／禁用后该快照失效。撤销、过期及删除账号继续沿用现有机制。公共读取保持实时校验，私人汇总及同版本分享准备复用 5 分钟缓存；切图表、展开明细、点趋势不发请求。群榜刷新后，若群汇总缓存比榜单更新版本更旧，仅补读该群汇总，避免旧总量配新榜单。

图片为白底、系统字体和普通数字；按所选工具／模型生成占比与趋势海报，携带包内原始固定小程序码。两种榜单图均绘制真实头像，无头像保留昵称占位。头像通过正式接口读取真实图片字节，直接以 Data URI 解码进画布，避免旧运行环境文件 URL；不写头像临时文件。

画布图片解码兼容依据：[微信官方 API 类型定义 Image.src](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)，基础库 2.11.0 起支持 Data URI。

开发者工具的原生图片分享面板可能无法读取画布临时文件，出现裂图。群分析页在模拟器中读取实际导出的 PNG 字节，使用内存 Data URI 打开图片预览；不改写 localhost 端口、不重新请求群数据。手机端继续使用原生图片分享菜单，不支持或打开失败时退回图片预览。导出或读取失败显示重新生成入口；切换维度、离页或切账号后丢弃迟到结果。

## 验证与发布

新增服务端 SQLite/Worker 测试覆盖超过 50 人、可见性、设备过滤、缺价、北京时间、匿名分享、快照冲突及隐私失效；小程序测试覆盖本地交互、缓存合并、迟到响应、真实头像绘制和海报数字一致性。正式 API 地址保持 `https://tokenrank.xmasdong.cn`，不引入 mock。GitHub 同步、Worker 部署及小程序上传／审核分别进行。

2026-10-31：在微信开发者工具 Stable 2.02.2608040（基础库 3.8.0）使用正式群数据复现原生面板裂图，确认原导出 PNG 可完整解码；改后模拟器实际显示完整的 1000×1640 海报。手机端原生分享分支由单元测试覆盖，本次未做手机实测。验收截图和导出文件仅保存在被忽略的本地产物目录。
