# 上个月用量与分享

「上个月」是独立周期 `last_month`，按北京时间上一个完整自然月的 1 日至最后一天统计。例如 2026 年 11 月打开时为 `2026-10-01 — 2026-10-31`；「近 30 天」继续使用含今天的滚动 30 天，两者不互换。大小月、闰年 2 月及跨年均按实际日历处理。

入口：

- 我的顶部周期选择「上个月」，查看含缓存总用量、输入／输出／缓存明细、工具／模型和 API 等值估算。
- 可直接转发该月用量，或进入「分享图片」选择用量账单、Token 卡片、排行榜、工具偏好。图片沿用固定小程序码，显示原始起止日期。缺少金额仍标为未同步／未计价。
- 群榜列表、群榜、广场及个人／群工具模型分析同步支持「上个月」。本群分析的海报与转发记录使用同一月份快照；图表逐日覆盖整月（28／29／30／31 天）。
- 工具／模型趋势榜的「上个月」与再前一个完整自然月比较；分享链接携带固定月末日期，后来打开仍展示该月份。

分享存储原始 `from`、`to`，跨月打开或发起同期 PK 时按原区间读取，不能用当下的“上个月”重新解释旧分享。内存缓存沿用北京时间日期键，跨日／跨月自动换键；同日返回和切换图表继续复用缓存。

服务端 `/api/my/usage`、`/api/my/rankings`、`/api/leaderboard`、`/api/my/analysis`、`/api/insights`、群分析、趋势榜及相关分享／PK 支持 `period=last_month`。继续从正式已上报日桶读取，不重算、不清空线上数据，也不需要用户升级电脑采集器。没有上月记录时明确显示暂无同步记录。

本次无需数据库迁移。验证覆盖北京时间月初、闰年、跨年、31 日完整趋势、金额／排名一致、旧分享跨月读取与对比、月切换缓存失效，以及手机原有分享样式的日期和标签。GitHub 同步、Worker 部署和小程序上传／审核／发布分别汇报。
